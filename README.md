# Microsoft Azure Live Coding - C++ Test Task

A small C++ test task focused on fixing a multithreaded logger implementation.

The task covers:

* static and thread_local
* object lifetime and static destruction order
* data races and synchronization
* std::atomic and std::mutex
* thread-safe containers
* C++ memory model basics
* safe API design in concurrent code

The goal is to identify concurrency and lifetime issues in the initial implementation and refactor it into a correct, thread-safe solution.

Target level: Strong Middle / Senior C++

Inspired by the type of systems and concurrency problems that may appear in live-coding interviews for infrastructure-oriented teams such as Microsoft Azure.
